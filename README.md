# Blank (text-only launcher widget)

Upload everything (including `.github`) to a GitHub repo, run Actions > Build IPA, download the `Blank-ipa` artifact.

- `Blank.ipa`: in-app editor syncs to the widget (needs an App Group). Try this first.
- `Blank-no-sync.ipa`: use if Sideloadly errors on the first one. Then pick apps from the dropdowns in the widget's Edit Widget screen.
